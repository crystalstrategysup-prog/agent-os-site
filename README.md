# Crystal AgentOS website

Static public website for Crystal AgentOS. It has no build step, analytics,
cookies, forms or runtime secrets.

Serve locally:

```bash
python3 -m http.server 8080
```

Public path: `https://crystalstrategy.ru/agent-os/`.
